Capacity & Embarked Status

Transport Capacity (18.01)

  • Datasheet Limit: Lists eligible model types/keywords and maximum model count. Multiple units can be embarked simultaneously if sufficient capacity remains for each whole unit.
  • Starting Embarked: During the Declare Battle Formations step, friendly units can start embarked within any friendly TRANSPORT with sufficient remaining capacity.
  • Dedicated Transports: Every friendly DEDICATED TRANSPORT must start the battle with at least one unit embarked within it. At the end of Declare Battle Formations, any empty DEDICATED TRANSPORT is destroyed (does not trigger on-destroyed rules).

While Embarked: Not on the Battlefield (01.02.04)

  • No Visibility or Range: Embarked units are not visible to other units (only to themselves), cannot see other units, and distances cannot be measured to/from them (except for their own abilities).
  • Targeting & Abilities: Cannot be targeted by attacks or rules requiring visibility, distance, or being on the battlefield. They still count as units in your army and can use/be affected by rules that do not require visibility, distance, or being on the battlefield (abilities only affect the TRANSPORT itself if they explicitly state they work while embarked).
  • Command Phase Battle-shock: Must still make Battle-shock rolls in your Command phase if already Battle-shocked or at/below Half-Strength.
  • Persisting Effects (01.02.02): Any persisting effects on a unit when it embarks are noted and continue to apply for their full duration if the unit is set up on the battlefield again.
  • Reviving Models (01.02.03): Models returned/added to an embarked unit are placed embarked if capacity remains; otherwise, those models are destroyed (without triggering on-destroyed rules).

Embarking

Embarking (18.02 & 18.02.01)

Once the first battle round has started, a friendly unit can embark within a friendly TRANSPORT model immediately after making a Normal, Advance, or Fall-Back move, if all of the following conditions apply:

  1. Within 3": Every model in the unit ends that move within 3" of that TRANSPORT (note: within 3", not wholly within).
  2. Not Set Up This Turn: The unit was not set up on the battlefield this turn (prevents disembarking and re-embarking in the same turn, or arriving from Reserves/Ingress and embarking in the same turn, unless a rule explicitly overrides this condition).
  3. Eligible Unit: The unit is eligible to embark per that TRANSPORT's datasheet.
  4. Sufficient Capacity: The TRANSPORT has enough remaining capacity for every model in the unit.

Effect: Remove the unit from the battlefield and place it to one side (it is now embarked and not on the battlefield).

Able to Embark (18.02.01): A unit is considered able to embark if it satisfies all four conditions above (plus any modifications to those conditions from other rules).

Disembarking

Disembarking Overview & Eligibility (18.03 & 18.04)

In the active player's Movement phase (Move Units step), each friendly embarked unit can be selected to move and make a Disembark Move (18.04).

When Eligible for a Disembark Move (18.04):

  • Embarked within a TRANSPORT model that is on the battlefield.
  • Did not embark within that TRANSPORT this phase.
  • That TRANSPORT has not made an Advance or Fall-Back move this phase.

General Set-Up Rules (03.02):

  • Coherency & Unengaged: Models must be set up wholly within the mode's set-up distance of the TRANSPORT, in Coherency (within 2" horiz / 5" vert of ≥1 model in the unit, and within 9" horiz / 5" vert of all models in the unit), and Unengaged (>2" horiz / >5" vert from enemy models, except in Combat Disembark).
  • If You Cannot Set Up (03.02.01): If all models cannot be legally set up during a voluntary Disembark Move, return the unit to the TRANSPORT; it counts as not having been selected to move yet.
  • Large Models (03.02.02): If a disembarking model's base is too large to physically fit wholly within 3", set it up with its base within 1" of the TRANSPORT's base/hull and unengaged.

Disembark Modes (18.04 & 09.02.02)

Before moving, you must select a disembark mode. Modes are mutually exclusive and must be assessed in the exact order below (you cannot choose a later mode if an earlier mode's conditions are met).

1. Rapid Disembark Set-Up: Wholly within 3"
Mandatory if the TRANSPORT made a Normal Move or Ingress Move this phase.
  • While Moving: Set up each model wholly within 3" of the TRANSPORT and unengaged (in coherency).
  • Ingress Limitation (18.04.01): If the TRANSPORT made an Ingress Move this turn, disembarking models must obey all placement rules and restrictions that the TRANSPORT had to follow during that Ingress Move (e.g. >8" from enemy units, outside opponent's deployment zone).
  • After Moving: Until the end of the turn, your unit cannot declare a charge (and cannot move again this phase).
2. Tactical Disembark Set-Up: Wholly within 3"
Mandatory if the TRANSPORT remained stationary or has not yet been selected to move this phase, AND the unit can be set up wholly within 3".
  • While Moving: Set up each model wholly within 3" of the TRANSPORT and unengaged (in coherency).
  • After Moving: Immediately select your unit to make a Normal Move or an Advance Move (if it makes a Normal Move, it can declare a charge later this turn).
3. Combat Disembark Set-Up: Wholly within 6"
Mandatory fallback if neither Rapid nor Tactical Disembark applies (e.g. Transport is surrounded so the unit cannot fit unengaged within 3").
  • Before Moving (Hazard Roll): Make a Hazard Roll (06.03) for each model in the unit: roll 1D6 per model; for each roll of 1–2, the unit suffers 1 Mortal Wound (or 3 MW if all models in the unit are MONSTER/VEHICLE).
  • While Moving: Set up each model wholly within 6" of the TRANSPORT (in coherency). Each model can be set up engaged with one or more enemy units that the TRANSPORT is engaged with (cannot engage enemy units the Transport is not engaged with).
  • After Moving: Your unit becomes Battle-shocked and, until the end of the turn, cannot declare a charge.

Destroyed Transports

Emergency Disembark Move (18.05) Set-Up: Wholly within 6"
Mandatory when a TRANSPORT is destroyed. Resolved by the active player BEFORE removing the TRANSPORT model and BEFORE rolling Deadly Demise (24.08).
  • Before Moving (Hazard Roll): Make a Hazard Roll (06.03) for each model in the unit (roll 1D6 per model: each 1–2 inflicts 1 Mortal Wound, or 3 MW if MONSTER/VEHICLE).
  • While Moving (Strict Placement Priority): Set up each model in coherency:
    1. Unengaged First: Wholly within 6" of the TRANSPORT, as close as possible (base-to-base/hull contact if possible) to the TRANSPORT, and unengaged.
    2. Engaged Fallback: Only if the above is not possible while remaining unengaged, set up that model wholly within 6" of the TRANSPORT, as close as possible to the TRANSPORT, and engaged.
    3. Cannot Be Set Up: Any model that still cannot be legally set up is destroyed.
  • After Moving: Your unit becomes Battle-shocked and, until the end of the turn, cannot declare a charge.
  • Multiple Embarked Units: If multiple units are embarked, the TRANSPORT's controlling player chooses the order in which they make their Emergency Disembark Moves.

Special Disembark Moves & Core Abilities

Special Disembark Move Types (18.06 & 18.07)

Used only when a datasheet or detachment rule explicitly instructs a unit to make one of these moves:

  • Assault Disembark Move (18.06):
    • When Eligible: As stated in the rule allowing it, provided the unit is embarked on the battlefield, did not embark this phase, and the TRANSPORT has not Advanced or Fallen Back this phase.
    • While/After Moving: Set up wholly within 3" (unengaged, in coherency). Has no charge restriction (unit remains eligible to declare a charge even after the TRANSPORT made a Normal Move).
  • Shock Disembark Move (18.07):
    • When Eligible: As stated in the rule allowing it, provided the unit is embarked on the battlefield and did not embark this phase (does not require the Transport to not have Advanced if the granting rule allows it).
    • While/After Moving: Set up wholly within 3" (unengaged, in coherency). Until the end of the turn, the unit cannot declare a charge.

Related Core Abilities (24)

  • Firing Deck X (24.14): In your Shooting phase, when the TRANSPORT is selected to shoot with ≥1 embarked units:
    1. Select up to X embarked models (excluding models whose units have already been selected to shoot this phase).
    2. For each selected model, select one ranged weapon (excluding [ONE SHOT] weapons).
    3. Until the TRANSPORT resolves all of its attacks, the TRANSPORT counts as equipped with those weapons in addition to its own.
    4. Until the end of the turn, units embarked within this TRANSPORT are not eligible to shoot.
    Note: Cannot be used with Fire Overwatch (out-of-phase rules). Uses the TRANSPORT's visibility, BS modifiers, and position.
  • Deadly Demise X (24.08): When a TRANSPORT with Deadly Demise is destroyed, roll one D6 after all embarked units have completed their Emergency Disembark Moves. On a 6, each unit within 6" (including the newly disembarked units) suffers X Mortal Wounds.
  • Scouts X" (24.31): A DEDICATED TRANSPORT wholly within your deployment zone can make a pre-battle Scout Move (up to X", ending >8" horizontally from all enemy units) if every model embarked within it has the Scouts ability.
